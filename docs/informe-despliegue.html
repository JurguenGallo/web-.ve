5. Plan de Despliegue — Paso a Paso

5.1 Pago y Contratación

  1. Ingresar a netcrohosting.com.ve
  2. Seleccionar Web Hosting cPanel Mx1 — $40/año
  3. Agregar dominio simenergy.com.ve — $15/año
  4. Pagar vía Binance Pay o PayPal — Total: $55 USD
  5. Recibir credenciales del cPanel (IP, usuario, contraseña)

5.2 Preparar el Sitio (está listo — se sube directo)

El sitio estático ya está generado en frontend/public/ con todos los archivos HTML, CSS, JS, imágenes y fuentes optimizados.

5.3 Subir Archivos al Hosting

Opción A — cPanel File Manager:

  1. Entrar a cPanel → File Manager → public_html
  2. Subir todo el contenido de frontend/public/
  3. Extraer si viene en .zip

Opción B — FTP (recomendado):

# Conectar por FTP (usar FileZilla o similar)
Servidor: ftp.tudominio.com.ve  (o la IP)
Usuario:  (el que dé Netcro)
Puerto:  21

# Subir la carpeta public al servidor
# Arrastrar todo el contenido de frontend/public/ a public_html/

Opción C — Node.js script de deploy:

# Desde la raíz del proyecto en tu PC
cd C:\Users\Usuario\Documents\GitHub\web-.ve

# Si tienes SSH habilitado (preguntar a Netcro)
scp -r frontend/public/* usuario@IP:/home/usuario/public_html/

5.4 Configurar Dominio

  1. En cPanel ir a Domains → Addon Domains
  2. Agregar simenergy.com.ve apuntando a public_html
  3. Si el dominio ya está registrado, cambiar los nameservers a los de Netcro
Nota: Si el dominio .ve lo registraste con Netcro, ellos lo configuran automáticamente. No necesitas hacer nada más.

5.5 SSL (HTTPS)

  1. En cPanel ir a SSL/TLS → Let's Encrypt
  2. Seleccionar simenergy.com.ve y emitir certificado
  3. Activar Auto SSL para renovación automática cada 90 días

5.6 Verificar que todo funciona

  • Abrir https://simenergy.com.ve y revisar que cargue
  • Probar todas las páginas: inicio, quiénes-somos, contacto, galería, etc.
  • Verificar imágenes, sliders y WhatsApp flotante
