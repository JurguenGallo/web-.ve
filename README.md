# SIM Energy - Clon Venezuela (.ve)

Este repositorio contiene la versión clonada y adaptada del sitio web oficial de **SIM Energy / SIM Industrial SAS** para el mercado de Venezuela.

## Propósito del Proyecto
Adaptar la identidad digital, el enfoque geográfico y la redacción comercial del sitio web de Colombia para la nueva sucursal y operaciones de la empresa en Venezuela.

## Estructura del Proyecto
- `/sitio-estatico`: Contiene los archivos estáticos HTML, CSS, JS e imágenes del sitio web descargado.
- `plan.md`: Planificación del proyecto con los objetivos de migración y rediseño de contenido.
- `tasks.md`: Lista detallada de las tareas del proyecto y su estado de ejecución.
- `fix_seo.js`: Script en Node.js utilizado para resolver problemas SEO en la página de inicio.

## Desarrollo Colaborativo
Este proyecto se desarrolla de forma conjunta entre múltiples desarrolladores y agentes de IA. Se debe tener cuidado al realizar búsquedas y reemplazos globales para evitar pisar los cambios de otros agentes.
